

### 術科測驗流程（總時長：55分鐘）

[cite_start]在前置作業階段，考生需完成鋪床、模特兒就位、工具就位，並將毛巾放置於蒸氣消毒箱 [cite: 42][cite_start]。此階段不計時，待所有考生就位後才會開始統一計時 [cite: 42]。以下為正式測驗的各階段流程：

| 操作階段 | 時長 | 流程與檢核重點 | 配分 |
| :--- | :--- | :--- | :--- |
| **一、工作前準備** | 10分鐘 | 1. [cite_start]填寫皮膚管理顧客資料卡。所有欄位皆為必填，初階不需填寫臉部圖示 [cite: 43] [cite_start]<br> 2. 模特兒包頭並消毒雙手 [cite: 43] [cite_start]<br> 3. 眼唇與全臉乾淨卸妝 [cite: 43] [cite_start]<br> 4. 基礎清潔洗卸動作確實 [cite: 43] | 15% |
| **【換水時間】** | 不計時 | [cite_start]考生可離開考場至供水區更換水盆（考生不可交談） [cite: 43] | - |
| **二、去角質及臉部按摩** | 20分鐘 | 1. [cite_start]按摩範圍必須包含：臉部、頸部、前胸、肩頸 [cite: 43] [cite_start]<br> 2. 包含操作後之擦拭與清潔 [cite: 43] | 40% |
| **【換水時間】** | 不計時 | [cite_start]考生可離開考場至供水區更換水盆（考生不可交談） [cite: 43] | - |
| **三、粉刺清理** |  | 1. [cite_start]含敷粉刺水、熱毛巾包覆 [cite: 43] [cite_start]<br> 2. 工具與手部消毒 [cite: 43] [cite_start]<br> 3. 手工清粉刺操作（粉刺放置考場提供之黑色化妝棉） [cite: 43] [cite_start]<br> 4. 清潔後拍打化妝水收斂 [cite: 43] | 15% |
| **四、敷面及善後** | 10分鐘 | 1. [cite_start]敷面範圍：臉部至下顎（不可透膚） [cite: 43] [cite_start]<br> 2. 善後保養：卸除面膜、化妝水、精華液、乳液、隔離或防曬 [cite: 43] | 20% |
| **五、整體觀感與重大扣分** | 全程 | [cite_start]依據下方明確扣分標準執行 [cite: 43] | 10% |

### 明確扣分標準

[cite_start]為確保評審標準一致，除各階段技術評分外，測驗期間若有以下違規項目，將直接扣減總分 [cite: 48]：

| 違規項目 | 違規情節說明 | 扣分 |
| :--- | :--- | :--- |
| **應考期間手機鬧鈴響起** | [cite_start]考生或模特兒手機響起（重大違規） [cite: 49] | -100 |
| **使用錯誤技法造成受傷或操作錯誤部位** | [cite_start]造成顧客受傷（重大違規） [cite: 49] | -30 |
| **指甲違規** | [cite_start]考生雙手有立體造型/貼鑽，或長度長於指肉0.2公分 [cite: 49] | -20 |
| **毛巾違規** | [cite_start]全部毛巾非單一素色（未統一使用奶茶色） [cite: 49] | -10 |
| **飾品違規** | [cite_start]考生及模特兒配戴任何飾品、手錶、項鍊、戒指 [cite: 49] | -10 |
| **面膜違規** | [cite_start]面膜顏色透明、厚度可看見原本膚色，或未敷至下顎 [cite: 49] | -10 |
| **刺青違規** | [cite_start]模特兒操作部位有刺青（前胸以上） [cite: 49] | -10 |
| **隱私曝光違規** | [cite_start]未正確使用毛巾，使模特兒胸前美容衣曝光 [cite: 49] | -10 |
| **按摩手技方向錯誤** | [cite_start]操作過程按摩畫圈方向錯誤或過度拉扯 [cite: 49] | -10 |
| **產品標示違規** | [cite_start]產品中文標示不完整或過期（一項扣2分，最多扣10分） [cite: 49] | -10 |
| **服儀違規(考生)** | [cite_start]考生未穿規定工作服 [cite: 49] | -5 |
| **服儀違規(模特兒)** | [cite_start]模特兒未穿素色美容衣、或不符合規定 [cite: 49] | -5 |
| **包頭違規** | [cite_start]操作時模特兒頭髮未用毛巾包好 [cite: 49] | -5 |
| **衛生違規** | [cite_start]工作前手部未消毒、未戴口罩、頭髮未紮好 [cite: 49] | -5 |
| **垃圾袋/消毒袋違規** | [cite_start]未準備或未標示垃圾袋、待消毒袋、大待消毒袋 [cite: 49] | -5 |
| **桌面整潔違規** | [cite_start]工具使用未清潔擺放整齊 [cite: 49] | -5 |
